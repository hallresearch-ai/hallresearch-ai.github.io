Repository documentation

Shows simple attacks on a classifier based model extraction and adversarial examples.

Contents

  • Red_Teaming_an_XGBoost_model_Code_Apache2.ipynb: Jupyter notebook that loads credit_line_increase.csv, trains an XGBoost classifier, demonstrates a model extraction attack, and demonstrates a tree-informed adversarial example attack.
  • credit_line_increase.csv: Example credit line dataset used for model training and attack demos.
  • requirements.txt: Minimal Python dependencies needed to run the notebook.
  • LICENSE: Apache License 2.0.

What the Notebook Demonstrates

  1. Load the credit line dataset and define the model features and target.
  2. Split the data into train, validation, and test sets.
  3. Train one unconstrained XGBoost model on the training data.
  4. Inspect the fitted model with basic explanations such as score quality and feature importance.
  5. Run a simple model extraction attack by querying the black-box model on synthetic inputs and training a surrogate model to imitate its outputs.
  6. Demonstrate a tree-informed adversarial example attack that uses the extracted surrogate model to infer a subtle, plausible one-feature edit to a customer record.

Setup

From the repository root, create and activate a Python virtual environment:

python3 -m venv .venv
source .venv/bin/activate

Install the dependencies:

python -m pip install --upgrade pip
python -m pip install -r requirements.txt

Start Jupyter:

jupyter notebook

Then open Red_Teaming_an_XGBoost_model_Code_Apache2.ipynb and run the cells in order.
